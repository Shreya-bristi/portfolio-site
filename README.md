# Shreya Pramanik — Portfolio

Personal portfolio site built with React + Vite.

## Quick Start

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`

## Deploy to Vercel (free)

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → Sign in with GitHub
3. Click **Import Project** → select this repo
4. Click **Deploy** — done. Live in ~60 seconds.

## Customizing

All content lives in the `C` config object at the top of `src/Portfolio.jsx`.
Edit that one object to update every section on the site.

### To add your resume:
Drop `ShreyaPramanik_resumeDS.pdf` into the `public/` folder.

### To add a custom domain:
In Vercel dashboard → Settings → Domains → add your domain.

## Build for production

```bash
npm run build
```

Output goes to `dist/` — upload anywhere that serves static files.
